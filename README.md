# Library Management System (Java)

## Description
A simple console-based Library Management System built using Java and OOP concepts.

## Features
- Add books
- View books
- Issue books
- Return books
- Basic login authentication

## Technologies Used
- Java
- OOP (Classes, Objects)
- ArrayList

## How to Run
1. Compile: javac LibraryManagementSystem.java
2. Run: java LibraryManagementSystem
